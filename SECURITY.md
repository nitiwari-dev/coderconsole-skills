# Security Policy

## Supported Versions

Security fixes are provided for the latest released version. Until the first
versioned release, the `main` branch is the supported version.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| `main` (before the first release) | Yes |
| Older releases | No |

## Reporting a Vulnerability

Please report suspected vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/nitiwari-dev/coderconsole-skills/security/advisories/new).
Do not report security issues in public issues or pull requests.

Include a description of the affected version or commit, the impact, and
steps to reproduce the issue. Avoid including real credentials, personal
information, or other sensitive data in the report.

Maintainers aim to acknowledge reports within five business days and provide
status updates at least every ten business days while investigating. We will
share whether the report is accepted, request any needed details, and coordinate
a fix and public disclosure with the reporter. If the issue is declined, we
will explain why when possible.

If private vulnerability reporting is unavailable for this repository, open a
public issue asking maintainers for a private reporting channel. Do not include
vulnerability details in that issue.
